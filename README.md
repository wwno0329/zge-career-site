## 配色调整

打开 `css/style.css` 最上面的 `:root`：
- `--accent-1`（青色 #22d3ee）、`--accent-2`（蓝色 #3b82f6）、`--accent-3`（紫色 #8b5cf6）是主色
- `--bg`（#05070f）是背景色
改这几个值就能整体换色调。

## 上线（免费）

- **GitHub Pages**：把整个文件夹推送到 GitHub 仓库，Settings → Pages 开启即可。
- **Vercel / Netlify**：注册后直接拖拽文件夹上传，自动生成网址。
- **自己的域名**：买个域名（如 .com / .cn），在 Vercel/Cloudflare Pages 上绑定，约几十元/年。
